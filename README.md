# Data Acquisition, Cleaning and Preprocessing

## Project Overview
This project focuses on data acquisition, cleaning, and preprocessing using Python. The main objective is to prepare raw data for further analysis by identifying and handling missing values, checking duplicate records, and organizing the dataset into a suitable format.

## Tools and Technologies
- Python
- Google Colab
- Pandas
- NumPy
- GitHub

## Project Workflow
1. **Data Acquisition:** Loaded the dataset into the Python environment.
2. **Data Inspection:** Examined the dataset structure, columns, and data types.
3. **Data Cleaning:** Checked for missing values and duplicate records.
4. **Data Preprocessing:** Prepared and organized the data for further analysis.
5. **Data Export:** Saved the processed dataset as a CSV file.

## Files Included
- `data_acquisition_cleaning.ipynb` – Jupyter Notebook containing the Python code and workflow.
- `titanic_cleaned.csv` – Cleaned dataset.

## Outcome
The project demonstrates basic data handling and preprocessing skills using Python. The cleaned dataset can be used for further exploratory data analysis and machine learning tasks.
